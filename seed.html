🗄️ Import Data ke Supabase

Jalankan sekali setelah deploy pertama untuk pindahkan semua data dari browser ke database.

Menunggu
1 Pastikan sudah login
Harus login sebagai Owner sebelum import. Login →
2 Buka di browser yang punya data localStorage
Buka halaman ini di browser/komputer yang sebelumnya dipakai untuk mencatat data. Data akan dibaca dari localStorage browser tersebut.
3 Klik Import
Proses import akan berjalan otomatis. Jangan tutup halaman sampai selesai.
